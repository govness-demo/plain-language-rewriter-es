# Plain-language rewriting skill (Spanish)

Rewrites administrative Spanish into plain language that follows the State's writing guide.

## Overview

Rules, examples and a checklist from the State's plain-language guide, packaged as an agent skill. Keeps legal meaning; flags terms it cannot simplify safely.
